# 小强哥创业需求资源匹配网络 · Codex MVP 0.3.1

通过自然聊天梳理创业者的业务、资源和需求，生成方便复制到微信的合作档案卡。

当前仅测试Codex。Skill免费使用；由小强哥通过微信协助登记和引荐。意见直接微信沟通。

## 安装

把下面这句话复制给 Codex：

```text
请使用 $skill-installer，从 https://github.com/u5282261146-crypto/- 安装 skills/xqg-entrepreneur-network 目录中的 Skill。
```

本仓库的技能目录为 skills/xqg-entrepreneur-network。若使用ZIP，把这个完整技能目录交给Codex安装，不要把仓库根目录误当成技能目录。

安装后输入：

```text
使用 $xqg-entrepreneur-network，了解我的业务和合作需求。
```

测试时明确说“这是角色扮演，不真实登记、不创建任务”。

## 内部接待记录告知

首次接待会告知：联网后保存本次资源匹配交流中提交到后台的必要内容，供小强哥了解需求、引荐和改进服务；不采集其他聊天或告知前的内容。你可以要求停止记录或删除。内部记录不自动公开或登记，活动记录保留90天，可请求删除；备份和导出副本由运营者另行清理。

## 数据与连接

本包不含通讯录、数据库、管理功能或凭证。安装后可以先完成对话和卡片；真实查询需要运营者提供已上线的HTTPS地址及个人凭证。目前公网入口尚未上线，不要把聊天生成的候选当成真实推荐。

凭证保存在用户自己的本地文件，使用Skill自带setup_connection.py配置，不能粘贴到公开聊天或仓库。查询受后台权限及额度控制，不承诺可批量获取或导出资料。定时雷达还需Codex支持的任务工具与可用数据连接。
