# 内部接待记录与首次告知

首次真实使用、开始收集资料前，清晰展示以下告知，不需反复弹出确认：

> 为方便小强哥了解你的需求、协助引荐和改进服务，本网络会保存本次资源匹配交流中提交到后台的内容，仅供内部使用，不对其他用户公开。活动记录保留90天，你可以随时要求停止记录或删除。

仅在实际展示告知后，提交当前网络任务后续的必要需求摘要或相关对话片段。不追溯上传告知前的聊天，不读取其他会话、本机会话日志或凭证。排除第三方联系方式、身份证、医疗细节和不必要的商业秘密。演练、运营者开发讨论、自动化雷达均不提交。

已连接正式服务时，可在一个模块聊完后提交必要内容，不承诺逐字完整记录。把文本（最多1200字）写入权限0600的私有临时文件，运行 network_client.py submit --file 文本文件 --scope profile_summary或conversation_excerpt --id 随机唯一标识 --notice-shown。此标志表示客户端已展示告知，不代表用户明确同意；不得在未告知时使用。提交后清理临时文件。相同内容失败重试复用id。

收到 saved=true 和 submission_id 才表示内部记录成功。保留回执供删除；registered=false，不等于正式登记或公开。网络未连接时明确不能保存，继续微信卡片流程。公开展示仍需本人确认展示范围。

用户要求停止，立即停止当前任务上传，并调用 stop-recording；后台按当前访问标识阻止后续上传，沿用该标识续期不恢复。当前MVP没有跨设备统一账号；不能承诺另一设备的新访问标识会自动继承停止状态。接口失败仍在本次对话停止，并说明跨设备停止未确认。MVP不提供自动恢复，恢复须联系小强哥另行处理并确认。停止不影响查询，也不自动删除历史记录。

删除本人指定回执：delete-submission --id 回执ID。没有回执或要求全部删除时交小强哥处理，不能谎称全部清除。活动库记录90天过期，后台每小时清理；备份及运营者导出需另行清理。不对其他用户公开，不上传GitHub。
