# Codex MVP 范围

当前0.3.0只面向使用Codex的创业者测试。Kimi、豆包、ChatGPT插件市场及Claude Code适配暂停；不引导用户安装未实测入口。反馈直接通过小强哥微信。

分发标准 Skill 文件夹；本机 Codex 已安装。GitHub 仓库尚未发布，官方公共插件目录尚未提交。发布包不包含数据库、原始名单、访问凭证、operator.local.json或运营管理脚本。

查询能力依赖真实服务连接。本地只读底库属于运营者环境，不代表所有安装者都能访问。共享查询服务已在运营者Mac mini运行，但只有本机监听，未提供公网地址；数据无连接时仍能聊天和生成登记卡片。

定时雷达还需宿主正式调度及通知工具。模拟中不创建真实任务。安装 Skill 不自动获得记忆、查询、登记、消息或后台任务权限。
