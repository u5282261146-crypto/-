# 小强哥 Business Network

**跟 AI 聊聊你的需求和业务，找合作伙伴、找客户，让合作机会持续找到你。**

这是一个面向各地创业者的需求与资源匹配网络，也欢迎海外及跨境创业者参与。安装到 Codex 后，就可以用自然语言寻找合作机会。免费使用。

## 你可以在这里做四件事

### 1. 发布需求，搜索合作伙伴

告诉 AI 你想解决什么问题、需要什么资源，它会帮你梳理需求，在网络中搜索相关创业者，筛选适合进一步沟通的合作伙伴。

比如：“我在苏州做面料生产，想找懂传统企业 AI 落地的人，先聊聊从哪个环节开始。”

**先说需求，就能开始找。** 想把需求发布到网络里，再由助手帮你整理成卡片，交给小强哥登记。

### 2. 发布资源或供给，寻找有明确需求的客户

介绍你能提供的产品、服务、经验或渠道，AI 会根据这些信息，搜索网络中已经发布相关需求的人，帮你找到更值得沟通的潜在客户。

比如：“我们能提供防水特种面料，支持批量定制研发，帮我看看有没有人在找这类供应商。”

你也可以把自己的供给发布到网络，让正在找这些产品或服务的创业者发现你。

### 3. 留下需求与资源，让后来的创业者找到你

找完这一轮，也可以把自己的需求和资源一起留下。助手会整理一张清晰的合作档案卡，你确认后发给小强哥完成登记与展示。

后续加入网络的创业者在查询相关需求或供给时，也有机会找到你。**主动找合作，也给自己留一个持续被发现的合作入口。** 越早登记，就能越早参与匹配；业务或需求有变化时，回来更新即可。

### 4. 设置机会雷达，定期发现新合作

你可以让 Codex 每天、每周或每月扫描一次，寻找与你的需求、产品或服务相关的合作机会。

比如：“每周帮我看看，有没有新增的特种面料采购需求，有合适的再提醒我。”

网络资料会随着创业者加入和需求、资源更新而增加。雷达帮你持续关注这些变化，减少反复查找；助手会检查你的 Codex 是否支持定时任务，并协助设置。
